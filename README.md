# Python OOP Practice

Коллекция задач по объектно-ориентированному программированию.

## 📂 Проекты

1. **Library** — управление библиотекой (выдача, возврат, поиск по автору)
2. **Shopping Cart** — корзина с фильтрацией по наличию на складе
3. **Logging System** — логгер с обработчиками и временными метками
4. **Task Manager** — задачи с приоритетами и статусом
5. **Bank Account System** — счета с процентами и типами
6. **Integer Container** — контейнер с медианой

## 🛠️ Что использовано

- **ООП:** наследование, полиморфизм, инкапсуляция, абстракция
- **Стандартная библиотека:** `dataclasses`, `abc`, `datetime`
- **Магические методы:** `__str__`, `__repr__`, `__len__`, `__iter__`, `__call__`
- **Декораторы:** `@property`, `@classmethod`, `@staticmethod`
